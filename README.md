# RIMSTORE - интернет-магазин колёсных дисков 

## Структура проекта:
```
online-shop/
├── index.html          — одна страница, семантическая разметка
├── README.md           — описание проекта
├── css/
│   └── style.css       — все стили + медиазапросы
├── img/
│   ├── favicon.svg     — фавикон
│   └── product-*.svg   — обложки товаров
└── js/
    ├── data.js         — каталог товаров (данные отдельно)
    ├── cart.js         — логика корзины + localStorage
    └── app.js          — рендер карточек, форма, обработчики
```
## Функционал:
- каталог товаров с карточками
- корзина с сохранением выбранных товаров, изменением их количества и пересчётом суммы
- форма оформления заказа + `localStorage`
- адаптивный дизайн
- форма оформления заказа

## Технологии:
- HTML5 (семантическая разметка)
- CSS3 (переменные, flex, grid, медиазапросы)
- JavaScript (без фреймворков)
